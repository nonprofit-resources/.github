## Contribute

- Browse the catalog on the site, then open a PR or use **Submit a resource**
- We accept: nonprofit vendor plans, DIY options, free/open software, and meta-directories
- Prefer linking [AlternativeTo](https://alternativeto.net/) when suggesting substitutes
